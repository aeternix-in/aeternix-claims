Test fixture for the Aeternix extension. Not a real payer system. Data stays in this browser.

What this is

A stand-in for a payer portal, so the extension can be shown and tested without touching a real one. It has the three pages the extension works on:

  • Claim list: the extension reads each row's status and sends it to Aeternix.
  • Claim form: the extension fills the fields and attaches the documents. You press Submit.
  • Confirmation page: the extension reads the claim reference so Aeternix can record the submission.

The claim list has a simulator panel for playing the payer: raise a query, approve, deduct, pay. The selectors for this fixture are in backend/app/adapters/selectors/mock.yaml, which is also the worked example for capturing a real portal.
